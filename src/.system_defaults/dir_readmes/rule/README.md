# Rules (RULE)
    
    Rules define global constraints, policies, or invariants that apply across multiple Requirements.
    
    ## Naming Convention
    - **File**: `RULE-{Domain}-{Number}.md`
    - **ID Pattern**: `^RULE-([A-Z]+)-(\d{3})$`
    
    ## Required Metadata
    - `ID`: Must match filename.
    - `Priority`: Low | Medium | High | Critical.
